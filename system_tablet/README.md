# التطبيق رقم 2 — نظام إدارة التمارين (تابلت)

تطبيق Android **مستقل تماماً** عن تطبيق المحكمين (`flutter_app/`).

| العنصر | القيمة |
|--------|--------|
| المجلد | `system_tablet/` |
| Package | `com.lf.systemtablet` |
| الاسم | نظام إدارة التمارين |
| التقنية | WebView يعرض النظام الكامل من السيرفر بنسبة 100٪ |
| الاتصال | Wi‑Fi محلي (IP:Port محفوظان) |

## ما لا يفعله هذا التطبيق

- لا يعدّل تطبيق المحكمين.
- لا يعيد تصميم واجهة النظام.
- لا يستبدل صلاحيات السيرفر.

## البناء

### المتطلبات

- Android Studio Ladybug+ أو JDK 17
- Android SDK 35

### أوامر

```bat
cd system_tablet
BUILD_APK.bat
```

أو:

```bat
gradlew.bat assembleRelease
```

مخرج APK:

- `system_tablet/app/build/outputs/apk/release/app-release-unsigned.apk`
- بعد التوقيع (أو debug): يُنسخ أيضاً إلى `dist/system-tablet-v1.0.0.apk` عبر سكربت البناء.

للبناء السريع بدون توقيع إنتاجي:

```bat
gradlew.bat assembleDebug
```

## الاستخدام

1. شغّل سيرفر النظام على الشبكة المحلية (`run.bat` — المنفذ الافتراضي 8005).
2. ثبّت APK على التابلت (10–12 إنش).
3. عند أول تشغيل: أدخل IP السيرفر والمنفذ (PIN لاحقاً للإعدادات: `2468`).
4. يفتح النظام الكامل بنفس واجهة الكمبيوتر/السيرفر.
5. سجّل الدخول بحسابك المعتاد — الصلاحيات كما على السيرفر.

### الإيماءات

- Pinch Zoom In/Out بإصبعين
- تحريك الصفحة أثناء التكبير
- ضغط مزدوج أو زر «إعادة التكبير» لإعادة 100٪
- لا يتم Refresh عند السحب

### أوضاع التشغيل

- **الوضع العادي**: استخدام النظام من التابلت فقط.
- **التحكم المباشر (Live Remote Control)**:
  1. على الكمبيوتر/البروجيكتور افتح: `http://<IP>:8005/presentation/live`
  2. من التابلت: سجّل الدخول ثم «بدء التحكم المباشر»
  3. تنعكس الصفحات/التبويبات/التكبير على شاشة العرض فوراً (SSE + WebSocket)
  4. أزرار: بدء / إيقاف / اختيار شاشة / قفل / إنهاء الجلسة

المخوّلون بالتحكم: إدارة النظام، السيطرة، التخطيط.

إيقاف إداري: قائمة إدارة النظام ← **إدارة التحكم المباشر**.

## السيرفر

مسارات مضافة (لا تمس تطبيق المحكمين):

- `/presentation/live` — شاشة العرض
- `/api/remote-control/*` — جلسة، أوامر، SSE
- `/admin/remote-control` — إدارة الجلسات وسجل Audit
- WebSocket على المنفذ `PORT+1` (مثل 8006)

## ملاحظة

محتوى الصفحات = نفس Flask. أي تحديث على السيرفر يظهر تلقائياً في التطبيق دون إعادة بناء APK (ما عدا تغييرات غلاف Android نفسه).
