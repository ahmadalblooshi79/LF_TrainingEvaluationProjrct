### Classification terminology

Production labels from `grade_label_from_percent` are:

ممتاز / جيد جدا / جيد / مقبول / راسب

The request UI used «جيد جداً». Reports use the **real system term** «جيد جدا». Alias «جيد جداً» / «متوسط» are normalized, not reinterpreted.

Thresholds were **not** duplicated; they are the existing percent bands (<60 راسب, <70 مقبول, <80 جيد, <90 جيد جدا, else ممتاز).

### Approval scope (item 42)

- **Old export** (list-level): every list in scope, including empty (`غير مدخلة`) and pending/approved. Unchanged.
- **New detailed report** (item-level): scored saved rows only (approved **and** pending). Empty lists, section rows, and «لا ينطبق»/NA are excluded. Scope note is shown on the Reports page and in the workbook summary.

Combined Procedure+Dilemma report was **not** added, to keep isolation strict.
