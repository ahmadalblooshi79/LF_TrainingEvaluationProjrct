# محرك الذكاء الاصطناعي المحلي — نظرة عامة

## الفكرة

محرك يعمل **بالكامل على الجهاز المحلي** بدون إنترنت، عبر مزودين محليين (الافتراضي: **Ollama**).  
المرحلة الأولى توفّر: الإعدادات، اختبار الاتصال، قائمة النماذج، واختبار Prompt بسيط.

## أين الزر؟

في **الصفحة الرئيسية** (`/dashboard`) تظهر بطاقة **مركز الذكاء الاصطناعي** (لإدارة النظام فقط افتراضياً).

## المسار

`/ai-center` — صفحة **مركز الذكاء الاصطناعي المحلي**.

## ما لم يُنفَّذ بعد

- مكتبة التقارير، قاعدة المعرفة، Embeddings
- تحليل أسلوب التقارير العسكرية
- إنشاء/تصدير تقارير Word أو PDF
- تحليل نتائج المحكمين

## العلاقة مع OpenAI الحالي

`app/ai_service.py` (اقتراحات سحابية) **منفصل** عن `app/ai_local_engine/`.
