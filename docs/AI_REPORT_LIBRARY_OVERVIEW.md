# مكتبة التقارير الذكية — نظرة عامة (المرحلة الثانية)

صفحة مستقلة داخل مركز الذكاء الاصطناعي: `/ai-center/report-library`

## الوظائف
- رفع DOCX/PDF مع بيانات التصنيف
- منع التكرار عبر SHA-256
- معالجة محلية: أقسام، جداول، وحدات، نقاط قوة/ضعف
- مراجعة يدوية وتصحيحات محفوظة
- Ollama/Qwen مساعد فقط عند انخفاض الثقة

## غير مشمول
Embeddings، Vector DB، إنشاء تقارير، LM Studio، llama.cpp
