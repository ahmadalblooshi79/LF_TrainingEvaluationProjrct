# تثبيت محرك الذكاء الاصطناعي المحلي

## متطلبات النظام

1. نظام تقييم التدريب يعمل عبر `run.bat` أو `run.py`.
2. تثبيت [Ollama](https://ollama.com) على نفس الجهاز (أو شبكة داخلية مصرح بها).
3. تشغيل خدمة Ollama محلياً على المنفذ الافتراضي `11434`.

## تثبيت نموذج يدوياً

النظام **لا** ينفّذ `ollama pull`. من طرفية خارج النظام:

```bat
ollama pull llama3
```

ثم من مركز الذكاء الاصطناعي: **تحديث قائمة النماذج** → اختيار النموذج → **حفظ**.

## التحقق السريع

```bat
curl http://127.0.0.1:11434/api/tags
```

## تشغيل التطبيق

```bat
run.bat
```

افتح `/dashboard` بحساب إدارة النظام ثم بطاقة **مركز الذكاء الاصطناعي**.
