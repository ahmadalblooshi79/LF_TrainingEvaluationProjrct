# دليل المستخدم — مكتبة التقارير

1. من مركز الذكاء الاصطناعي افتح **مكتبة التقارير الذكية**
2. **إضافة تقرير** أو **إضافة عدة تقارير**
3. اختر DOCX أو PDF نصي وأدخل البيانات
4. اضغط معالجة / فعّل المعالجة الفورية
5. من التفاصيل راجع الأقسام والوحدات والنقاط
6. من **مراجعة النقاط** عدّل النوع/الوحدة/الحالة

PDF المصور يظهر رسالة OCR ولن يُحلّل نصياً في هذه المرحلة.
