# استكشاف أخطاء المكتبة

| رسالة | الإجراء |
|-------|---------|
| الملف غير مدعوم | استخدم docx أو pdf |
| موجود مسبقاً | افتح الموجود أو فعّل نسخة جديدة |
| PDF مصور / OCR | وفّر نسخة نصية |
| تعذر قراءة Word | تحقق أن الملف docx سليم |
| لم تُكتشف وحدات/نقاط | راجع يدوياً من شاشة المراجعة |
| تعذر Ollama | المعالجة الأساسية تعمل؛ المساعدة الذكية تتخطى |
