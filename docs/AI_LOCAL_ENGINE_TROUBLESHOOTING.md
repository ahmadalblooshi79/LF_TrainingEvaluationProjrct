# استكشاف أخطاء المحرك المحلي

## تعذر الاتصال بـ Ollama

الرسالة: «تعذر الاتصال بخدمة Ollama…»

- تأكد أن Ollama يعمل.
- تحقق من العنوان: `http://127.0.0.1:11434`.
- لا تستخدم عناوين سحابية.

## النموذج غير مثبت

الرسالة: «النموذج المحدد غير مثبت محلياً…»

- ثبّت النموذج يدوياً: `ollama pull <name>`
- حدّث قائمة النماذج من الواجهة.
- النظام لا ينزّل النماذج تلقائياً.

## المزود غير جاهز (LM Studio / llama.cpp)

هذه المزودات هياكل للمرحلة اللاحقة — استخدم Ollama حالياً.

## انتهاء المهلة

زد `Timeout` في الإعدادات أو استخدم نموذجاً أصغر.

## النظام يعمل رغم توقف Ollama

نعم — الصفحة والإعدادات تعملان، وتظهر حالة الفشل دون تعطيل باقي النظام.
