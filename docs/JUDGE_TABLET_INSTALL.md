# تثبيت تطبيق المحكمين (تابلت Android)

## المتطلبات

- تابلت Android 10–12 إنش (Android 8+)
- اتصال WiFi بنفس شبكة السيرفر
- تشغيل **LF Training Evaluation Server** على جهاز Windows

## 0) تحديث السيرفر (مهم لتطبيق التابلت)

تطبيق التابلت يحتاج مسار `/api/mobile/v1/ping` على السيرفر. إذا ظهرت رسالة **«واجهة التطبيق غير متوفرة»**:

1. أوقف السيرفر الحالي.
2. ثبّت من جديد: `dist/LF_TrainingEvaluation_Setup.exe`
3. شغّل السيرفر وتحقق من المتصفح: `http://IP:8005/api/mobile/v1/ping` — يجب أن يظهر `{"ok": true, ...}`

## 1) تثبيت الـ APK

1. انسخ الملف `dist/LF_Judge_Tablet.apk` إلى التابلت (USB أو مشاركة ملف).
2. على التابلت: **الإعدادات → الأمان → تثبيت تطبيقات غير معروفة** (فعّل للمتصفح أو مدير الملفات).
3. افتح ملف APK واضغط **تثبيت**.

## 2) إعداد عنوان السيرفر

1. افتح التطبيق.
2. من شاشة الدخول اضغط **إعدادات السيرفر**.
3. أدخل IP وPort ثم اضغط **اختبار الاتصال** — يجب أن تظهر رسالة «نجح الاتصال».
4. اضغط **حفظ وإعادة الاتصال**.
5. ارجع لشاشة الدخول.

> تأكد أن جدار الحماية على Windows يسمح بالمنفذ 8005.

## 3) تسجيل الدخول

| الدور | طريقة الدخول |
|--------|----------------|
| محكم فردي | اسم المستخدم + كلمة المرور |
| كبير المحكمين | حساب `chief_judge` أو حسابك المخصص |
| تجريبي | `judge` / `demo123` أو `chief_judge` / `demo123` |

## 4) العمل دون اتصال (Offline)

- عند انقطاع WiFi يمكن **حفظ** التقييمات محلياً.
- عند عودة الشبكة تتم **المزامنة تلقائياً** عند فتح لوحة التحكم.
- زر **المزامنة** (أعلى الشاشة) يرفع العمليات المعلّقة يدوياً.

## 5) التكبير والتحريك

في شاشات الجداول (قوائم التقييم / التفاصيل):

- **إصبعان للتكبير/التصغير**
- **سحب بإصبع** للتحريك أثناء التكبير

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| فشل الدخول | تحقق من IP/Port وتشغيل السيرفر |
| لا تظهر قوائم | تأكد من تمرين نشط وإسناد المحكم |
| المزامنة فاشلة | أعد الاتصال بالWiFi واضغط زر المزامنة |
